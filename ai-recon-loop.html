AI Recon Loop
Bug Bounty · Autonomous Recon Pipeline
Phase 1 — Initialise
START Define Target Scope
Domain, IP range, programme scope rules, out-of-scope assets.
Phase 2 — Passive & Active Recon
RECON Basic Recon Sweep
AI executes a controlled initial sweep. Tools are scope-checked before running.
subfinder amass nmap -sV whatweb wafw00f httpx whois shodan theHarvester
SAVE Persist Output → project/recon/
All tool output is written to structured files. These become the permanent context window for this project.
project/recon/subdomains.txt project/recon/ports.json project/recon/tech-stack.md project/recon/urls.txt project/recon/notes.md
🧠 AI loads project/recon/ as context on every loop iteration — accumulated intelligence grows over time.
Phase 3 — AI Planning
SUGGEST AI Generates Command Candidates
Based on saved context, the AI proposes a ranked list of next commands grouped by attack surface.
dir/vhost bruteforce param fuzzing JS recon CVE matching auth testing CORS check SSRF probe SQLi scan
⚑ Phase 4 — Prediction Gate (Critical)
PREDICT AI Pre-Screens Each Candidate Command
Before anything runs, the AI simulates likely outcomes for each candidate — scoring risk, signal value, and path viability. Commands that would cause noise, crashes, rate-limits, or dead-ends are filtered out.
EXECUTE
High signal, low risk, within scope. Likely to yield useful output. Add to run queue.
DEFER
May trigger WAF / rate limit. Useful but risky — defer until stealthier approach confirmed.
SKIP
Dead-end, out-of-scope, crash risk, or forbidden by programme rules. Discarded.
🛡️ AI checks: scope compliance · WAF presence · rate-limit risk · crash potential · stealth cost · estimated signal-to-noise ratio
Phase 5 — Execution
EXEC Run Best Command(s)
Only pre-screened, approved commands execute. Output is captured, parsed, and appended to project/recon/. AI summarises findings in real-time.
stdout → file error handling timeout guard rate limiter scope re-check context update
Phase 6 — Triage
FLAG AI Evaluates & Flags Findings
AI scores each result against known vuln patterns. Anything with bounty potential is flagged with severity, evidence path, and suggested next steps. Findings written to project/findings/.
CVSS estimate PoC notes reproduction steps evidence saved severity: Critical/High/Med/Low
LOOP Deepen or Pivot — Back to Suggest
Context is richer. AI re-evaluates the attack surface and generates a new candidate list — progressively drilling toward high-value targets.
